Help — How this chatroom works

This chatroom allows users to sign up and log in using a username, password, and screen name. After logging in, users can create or join chatrooms. Chatrooms may optionally have a key (password) — if a room is locked, the user must provide the key to join. Rooms are listed in the "Available Rooms" panel. New rooms are broadcast to all connected clients. Messages typed in the current room will be sent to the server and broadcast only to occupants of that room. The UI updates without reloading the page using JavaScript fetch() for PHP endpoints and web sockets for live messaging. The chat interface allows private direct messages via a DM control (for grad students). All user sessions are tracked on the server; logging out removes the user from any room and ends the session.
